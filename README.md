# Kwacha!

Snap prices. Track change.

Kwacha! is a local price-tracking, cost-of-living, and inflation dashboard for Zambia.

It helps users capture everyday price snapshots, define a personal basket of goods, compare prices across shops, calculate personal basket inflation, and eventually forecast price changes using machine learning.

## Project Goals

- Track everyday prices
- Normalize prices by unit
- Compare shops and locations
- Calculate basket cost over time
- Compare personal inflation with public indicators
- Train basic forecasting models
- Serve predictions inside a personal app

## Tech Stack

- React + TypeScript + Vite + Tailwind
- FastAPI + SQLite
- Python collectors
- pandas + scikit-learn
- Google Colab notebooks

## First Milestone

A working local web app where a user can:

1. Add items
2. Add price observations
3. Define a basket
4. View basket cost
5. Export data for analysis
