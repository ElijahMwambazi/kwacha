# Model Card

## Model Name

Example: price_forecast_random_forest_v1

## Purpose

Predict the next price per unit for tracked basket items.

## Training Data

Describe:

- number of observations
- date range
- items included
- sources used

## Features

List features used by the model.

## Target

The value the model predicts.

## Metrics

- MAE
- RMSE
- R²
- Baseline comparison

## Limitations

- Small dataset
- Manual data may contain errors
- Scraped data may be incomplete
- Model may not generalize outside tracked locations

## Intended Use

Personal price tracking and educational forecasting.

## Not Intended For

Official inflation reporting or financial advice.
