# Project Brief

## Name

Kwacha!

## Concept

Kwacha! is a local price snapshot and inflation dashboard for tracking everyday prices in Zambia.

The name plays on two meanings:

1. Kwacha as the Zambian currency
2. “Kwacha!” as the imagined sound of capturing a price snapshot

## Problem

Official inflation statistics are useful, but they do not always reflect the personal experience of rising prices for a specific household, shop, location, or basket of goods.

## Goal

Build a personal app that tracks everyday prices, calculates personal basket inflation, and eventually predicts price movement using machine learning.

## Learning Goals

- Data collection
- Data cleaning
- Unit normalization
- SQLite data modeling
- Exploratory data analysis
- Inflation calculation
- Dashboard design
- Regression models
- Forecasting
- Model serving
